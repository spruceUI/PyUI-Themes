# `SPRUCE-Amethyst` *by* `brenonsc`

Dark, purple-accented take on the default spruce theme by tenlevels.

- True black backgrounds
- Purple accent instead of the original yellow, including app icons
- Colored main menu: yellow Favorites, purple Games, green Apps, blue Settings
- Onion-style white status icons (Wi-Fi, battery, volume)
